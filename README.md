Hello Everyone, Welcome to my network protocol repo. In this repo, I will be uploading redesigns or designs for current network protocols used within the internet infrastructure. Currently, I have redesigns for TCP, DNS and DHCP. Now for those who may be looking for implementation or test results, I currently do not have this at the moment. However, I do plan in the future to make client-side implementations of the redesigns but I cannot confirm this will actually happen. These designs are open-source and you can refer to the MIT license if you are worried about legal issues. If you do implement this, I only ask that you make sure this helps as many people as possible. 

Verification Confirmation
The instructions below can be used to verify my network protocol redesigns. This GPG verification was done to ensure that authenticity is maintained. 
1. gpg --import public-key.asc - This command allows you to import the public key on your device. You can run this command in PowerShell or the command terminal. 
2. gpg --verify "DHCP Redesign.pdf.asc" "DHCP Redesign.pdf" - This command  allows you to verify the signature for the DHCP redesign

Other verification command:
1. gpg --verify "DNS Redesign.pdf.asc" "DNS Redesign.pdf" - This command can be used to verify the signature for the DNS redesign
2. gpg --verify "TCP Redesign.pdf.asc" "TCP Redesign.pdf" - This command can be used to verify the signature for the TCP redesign
